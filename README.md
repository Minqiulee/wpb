一个加权泊松二项分布（Poisson Binomial Distribution）的建模与计算模块，用于评估某个观测结果在整体随机过程中的累积分布位置（百分位）。核心要求使用傅立叶变换（特征函数/单位根法）降低时间复杂度。

输入：
- 每次试验的成功概率列表 p_i（取值为0.3~0.5之间的16个离散有理小数）
- 对应的权重列表 w_i（体现各试验对总成功次数的贡献）
- 实际观测结果：各试验成功/失败的布尔序列

输出：
- 完整概率质量分布（PMF）及累积分布函数（CDF）数组
- 给定观测结果对应的 CDF 概率值及其百分位数值
- 边界情况处理：p_i 为 0 或 1、权重为零、观测结果超出可能取值范围时的行为
